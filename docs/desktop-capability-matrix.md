达到“已配置、已验证、已呈现”，否则不得在产品说明中称为桌面端已具备的能力。

## 验收规则

1. **已实现**：存在经过单元或契约测试的服务端逻辑。
2. **已接线**：桌面端能经受控 API 调用该逻辑，不能依赖手工数据库操作。
3. **已配置**：默认 Release、权限、目录挂载、模型路由或知识库均已准备好。
4. **已验证**：自动化端到端测试实际观察到预期的 Run、工具、证据或审计事实。
5. **已呈现**：用户可在界面理解输入、过程、结果与失败原因；原始事件名不等于产品呈现。

## 当前产品定位

当前桌面端是 **Runtime 提交、人工控制与诊断客户端**，不是第二套 Runtime。默认演示
闭环只授予只读 `demo-workspace` 的 `controlled_scan`；选择任意本地目录仍只会生成有界
清单，不会扩大容器可读范围。真实模型和业务 RAG 仍需由管理员在 Gateway/RAG 侧配置并
通过发布快照准入，桌面端不会把“未配置”伪装成模型或知识能力。
