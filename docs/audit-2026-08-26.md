## 3. 本轮已修复问题

1. **审计分页缺陷**：原先先取租户最早 1000 条再按 Run 过滤，较新的 Run 会“没有审计”。改为 SQL 过滤后分页，加入 Trace/Run 索引和游标测试。
2. **审计读取传输边界遗漏**：Runtime 查询 Governance 未携带已有工作负载身份/mTLS 选项；现与配置的服务身份一致，并验证传输参数。
3. **E2E 假阳性**：复用历史 Trace、仅检查事件名称可能误认旧事件。改为本轮 Trace，等待实际异步投递，校验持久化终态及工具业务状态。
4. **测试预算误判**：真实模型调用超过旧 30 秒 fixture 预算。仅将独立测试 fixture 的上限调整为 180 秒；不通过扩大用户发布预算掩盖超时问题。
5. **Web 重登录边界**：两层认证白名单不一致、短寿命 Token 被最小 TTL 延长、回跳路径反斜杠绕过风险；统一资源白名单、收紧 TTL 和站内路径校验。
6. **UI 报文过长/状态串台**：Web 第二次打开任务不再折叠、Desktop 全量 JSON 默认展开、换任务保留旧事件/审计/导出信息、旧异步响应覆盖新任务。已增加折叠组件与状态清理/响应保护。
7. **终态操作不一致**：LIMIT_EXCEEDED/REJECTED 仍显示控制动作；只读共享仍返回审批动作列表。现统一拒绝，增加终态和只读共享回归。
8. **表单输入 500/隐式转换**：损坏 JSON、数组/null、错误比例/金额/评分、错误 metadata、字符串租户白名单。现返回明确 422，不静默截断比例或将白名单拆为字符。
9. **测试导入边界**：Governance/Model Lab 测试可能导入其他工作目录的同名 app；补全本项目测试路径与 Infra 依赖声明。
10. **过时冒烟入口**：旧 RAG smoke 脚本仍 import 已迁走的 Runtime 应用。改为显式 `--running-platform` 后复用统一 HTTP 联调，不恢复跨应用 import。
11. **网关前端构建配置**：esbuild 构建脚本授权是未完成占位值；修正为单项许可后构建通过。
