# LLM Gateway 职责边界与调用协议

## 1. 定位

`llm-gateway` 是统一模型访问层。它把不同厂商和本地推理服务统一为
OpenAI-compatible API，并集中执行模型访问所需的安全、可靠性、计量和治理策略。

Gateway 负责：

- OpenAI-compatible API 和多厂商协议适配；
- primary、weighted、canary、fallback 模型路由；
- WebFlux SSE 流式转发；
- 限流、熔断、超时、重试和模型健康探测；
- 多租户 API Key、模型白名单和管理端鉴权；
- Token 计量、请求级成本预算、租户配额和成本报表；
- Prompt 模板、响应安全策略和 JSON Schema 校验；
- 请求审计、Trace、TTFT、TPOT、QPS、Tokens/s 和错误率。

Gateway 不负责：

- Agent Graph 和下一步动作决策；
- 短期或长期会话记忆；
- 文档解析、向量化、RAG 检索和 Rerank；
- 业务 Tool 注册、权限决策和执行编排；
- GMP 等具体业务流程状态机。

这些能力由 `rag-agent-service` 或其他业务 Agent 服务负责。Agent 服务仅通过
`/v1/chat/completions` 调用 Gateway，不能直接持有模型厂商密钥。

## 2. 全链路身份

OpenAI-compatible 请求正文保持厂商兼容格式，平台身份放在 HTTP Header 中：

| 逻辑字段 | HTTP Header | 来源与用途 |
|---|---|---|
| `trace_id` | `X-Trace-Id` | 跨 Gateway、Agent、RAG、Tool 的统一 Trace |
| `tenant_id` | `X-Tenant-Id` | 可重复声明，但最终值必须由 API Key 确认 |
| `user_id` | `X-User-Id` | 最终绑定到 API Key 解析出的用户 |
| `agent_id` | `X-Agent-Id` | 调用 Gateway 的 Agent 或应用标识 |
| `agent_version` | `X-Agent-Version` | Prompt、Graph 和发布版本关联 |
| `session_id` | `X-Session-Id` | 仅用于关联；Gateway 不读取或保存会话记忆 |
| `run_id` | `X-Run-Id` | 一次 Agent Graph 执行的实例 ID |
| `purpose` | `X-Purpose` | 成本归属、审计分类和策略匹配 |
| `cost_budget` | `X-Cost-Budget` | 请求预算，单位为 Gateway 基准币种 CNY |

此外，`X-Request-Id` 表示一次 Gateway HTTP 调用。一次 Agent `run_id` 可以包含多次
`request_id`，这些调用共享同一个 `trace_id`。

缺少 Agent 字段的普通 OpenAI 客户端仍可调用，Gateway 会使用
`direct-client`、`unversioned`、`stateless` 等明确默认值。生产 Agent 调用必须完整传递
上述字段。

## 3. 示例

```http
POST /v1/chat/completions
Content-Type: application/json
Accept: application/json
Authorization: Bearer tenant-api-key
X-Request-Id: req-01
X-Trace-Id: trace-20260725-01
X-Tenant-Id: pharma-a
X-User-Id: reviewer-1001
X-Agent-Id: gmp-review-agent
X-Agent-Version: 2026.07.25
X-Session-Id: session-2001
X-Run-Id: run-3001
X-Purpose: gmp-document-review
X-Cost-Budget: 2.50

{
  "model": "deepseek-v4-flash",
  "messages": [
    {"role": "system", "content": "Return the required review JSON only."},
    {"role": "user", "content": "Review the supplied evidence."}
  ]
}
```

`X-Cost-Budget` 是调用前准入预算。Gateway 使用 Tokenizer、输出分位数预测和目标路由中
最高可能价格计算预占成本；预测值超过预算时返回 `402 Payment Required`。模型完成后，
再使用厂商 `usage` 进行实际结算并释放多余预占。

## 4. 身份信任边界

`X-Tenant-Id` 不是鉴权凭证。Gateway 以 API Key 绑定的租户为准，Header 与绑定值不一致
时返回 `403 Forbidden`。这些内部身份只进入审计、用量、性能和 Trace 记录，不会转发给
OpenAI、DeepSeek、Claude 等外部模型厂商。

## 5. 历史兼容能力

原工程中的 LangChain4j 轻量 RAG、Tool Calling、Agent 反向代理、GMP 代理和 Agent Memory
已经默认关闭，仅用于历史演示：

```powershell
$env:ENHANCEMENT_LANGCHAIN4J_ENABLED="true"
$env:RAG_AGENT_ENABLED="true"
$env:GATEWAY_AGENT_MEMORY_ENABLED="true"
$env:GOVERNANCE_BASE_URL="http://localhost:8081"
$env:CONTROL_PLANE_BASE_URL="http://localhost:8082"
```

生产部署不应打开这些开关。专业 Agent/RAG 能力应部署在独立服务中。
